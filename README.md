# Clipboard Confessional

> Your clipboard confesses copied secrets and assigns penance.

A desktop tray tool that watches your clipboard and treats copied passwords, tokens, and sensitive notes as penitents needing confession. The twist is repeated copies trigger repeated penance, and clearing the clipboard pours holy water over the confessional.

## Features
- Monitor local clipboard entries and classify sensitive content
- Generate a confession journal with copied item type and age
- Assign penance tasks like rotate tokens or move notes to a password manager
- Show a holy-water animation and reset the confessional when clipboard is cleared

## Stack
- Electron
- SQLite
- Lottie

## Getting started
```
npm install && npm run dev
```
